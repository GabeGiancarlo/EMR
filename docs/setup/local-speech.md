# Optional local whisper.cpp transcription

This adapter is optional loopback development tooling. It is not a production speech service, not a hosted model API, and not an automated clinical decision feature. Authentication remains deferred: `x-nexus-actor` selects a local actor and is not a production identity proof.

No speech model is vendored in this repository. The optional helper builds the official whisper.cpp CLI and downloads a model onto the same machine. Nexus owns the adapter, validation and review workflow; it does not train a speech model from scratch or require a hosted speech API.

## Reproduce the Windows setup

From the repository in PowerShell, run `./tools/setup-local-speech.ps1`, then restart with `./tools/start-api.ps1`. The setup helper requires Visual Studio C++ build tools and CMake. It pins whisper.cpp [v1.9.5](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.5) to commit `d1be6fde11ac6e0407606b4e42fe72d34add8037` and checks `ggml-base.en.bin` against SHA-1 `137c40403d78fd54d454da0f9bd998f78703390c` from the [official model manifest](https://github.com/ggml-org/whisper.cpp/blob/v1.9.5/models/README.md). The [whisper.cpp README](https://github.com/ggml-org/whisper.cpp/blob/v1.9.5/README.md) describes the upstream recognizer and WAV format.

Source, build output and model stay in ignored `.local/whisper`. If both speech environment variables are unset, `start-api.ps1` detects the helper's executable and model and sets those variables for that process. Existing explicit configuration is respected. Running the API directly with Cargo does not perform this detection.

On November 2, 2026, the local CPU build and model checksum passed. A 13.6-second recording generated by Windows speech synthesis, containing only a software verification statement, was transcribed through both the actual API and browser. The returned words matched the known synthetic sentence; a manually selected excerpt was saved as a form draft with provenance. This verifies the connection and persistence, not accuracy on therapy recordings, accents, overlapping voices or medical terminology. No real patient audio was used.

## Unconfigured state

This is the default. It applies when either `NEXUS_WHISPER_CLI` or `NEXUS_WHISPER_MODEL` is unset, empty, relative, a URL, or not an existing file.

- Process startup prints `Optional local whisper.cpp: unconfigured`.
- `POST /api/speech/transcribe` returns HTTP 503 with code `speech_unconfigured` and an actionable message naming both variables.
- No shell is started, no hosted service is called, and no transcript is returned.
- The rest of the local API still runs.

Set the variables in the API process environment and restart the process. A request-time check is authoritative: a path that is missing when the request arrives stays unconfigured even if startup looked different.

## Working state

Both variables are absolute filesystem paths and both files exist when the request is handled:

- `NEXUS_WHISPER_CLI`: official whisper.cpp `whisper-cli` or `main` binary
- `NEXUS_WHISPER_MODEL`: local ggml model file

Startup prints `Optional local whisper.cpp: configured`. That only means the two paths existed at startup. It is still not a production deployment.

The API then runs exactly one fixed invocation, with the process working directory set to a unique temporary directory. The request cannot choose the binary, model, arguments, or paths:

```
whisper-cli -m <NEXUS_WHISPER_MODEL> -f input.wav -otxt -of output -nt
```

`-f` is the staged filename `input.wav`. `-of output` with `-otxt` writes `output.txt` in that directory. There is no prompt flag, no speaker diarization flag, and no shell.

## Request

`POST /api/speech/transcribe`

- Body: binary `audio/wav`, maximum 20 MiB
- `x-nexus-actor`: local staff UUID
- `x-nexus-client`: client UUID
- `x-nexus-consent`: consent UUID

The WAV must be RIFF/WAVE PCM 16-bit, mono, 16000 Hz, with consistent byte rate and block align, chunk sizes that fit inside the file, at least one sample, and duration of 10 minutes or less. The adapter does not transcode.

Authorization requires role `admin`, `clinical_lead`, or `clinician`. A clinician must be the client's primary clinician. The consent row must belong to the same client and organization, with kind exactly `recording`, `revoked_on` null, `granted_on` on or before the facility's calendar date, and `expires_on` null or on or after that date. A client without a facility uses UTC. Support staff can record consents but cannot transcribe; resource exceptions do not grant speech access. The form offers matching consent rows from the local workspace payload, but the API re-reads the database and does not trust that list. Staff, client assignment and consent are locked and revalidated in the same transaction as the completion audit. Locks are released while the recognizer runs.

One transcription runs at a time in this process. A second request receives HTTP 429. The child process is killed on drop and stopped if it exceeds 120 seconds. The temporary directory is named `nexus-whisper-<uuid>` and contains only that job's `input.wav` and `output.txt`. It is removed after success or failure. Audio and transcript text are not written to audit events or application logs.

The 10-minute duration is an input ceiling, not a processing-time guarantee. Longer audio or slower hardware can hit the two-minute execution limit; the response asks the operator to use a shorter recording. Files are read from disk with a 200001-byte ceiling before UTF-8 validation.

Audit rows record a read of the consent and the client, then, only after a transcript is produced and before it is returned, a completion action `transcribe` for the same consent and client ids. If that completion audit cannot be stored, the transcript is discarded and not returned.

## Response

```json
{
  "transcript": "draft text from the local CLI",
  "engine": "whisper.cpp",
  "manual_review_required": true
}
```

The transcript is the plain UTF-8 text from `output.txt`, at most 200000 bytes, without added speaker labels, signature, or generated clinical prose. The form UI inserts it into source text and clears previous field provenance. A person must review it before mapping fields or saving. Nothing is signed automatically.

Closing the browser does not cancel an in-flight local job. A hard kill of the API can leave a temp directory behind. Multiple API processes do not share the single-job lock.

Example against loopback only, after the variables are set and the API is restarted:

```
curl -sS -X POST -H "content-type: audio/wav" -H "x-nexus-actor: ACTOR_UUID" -H "x-nexus-client: CLIENT_UUID" -H "x-nexus-consent: CONSENT_UUID" --data-binary @recording.wav http://127.0.0.1:8090/api/speech/transcribe
```

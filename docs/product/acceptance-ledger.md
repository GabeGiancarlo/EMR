## End-to-end acceptance

The extended chain is not complete until one authorized encounter can proceed through controlled telehealth access, consented media capture, local recognition, corrected timestamps/speakers, source-linked draft, clinician review/sign/amend and approved patient-scoped retrieval. Each stage must preserve the patient/episode, versions, authorization, processing failures and retention treatment. Testing one stage does not establish this chain.

Each delivery checkpoint must record code paths, automated checks, observed browser paths, limitations and affected records in [verification.md](../development/verification.md). External exchange, identity, prescribing or payment integration cannot be accepted using a manually entered reference or synthetic provider response. Synthetic fixtures belong only in disposable tests; the normal application starts from user-created records.
